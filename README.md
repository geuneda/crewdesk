# crewdesk

A framework for running AI agents as team members: intake, shared work knowledge, approvals, and cost control, built simulation-first.

메일과 메신저로 업무를 받아 처리하는 AI 에이전트 사원을 조직에 배치하고 운영하기 위한 프레임워크입니다.

상태: 시뮬레이션 구현이 동작합니다. 모든 외부 의존은 더미 구현입니다. 실제 런타임과 채널 연동은 아직 없습니다.

## 풀려는 문제

에이전트 한 개를 잘 만드는 것과 에이전트를 여러 조직에 배치해 운영하는 것은 다른 문제입니다. 운영 단계에서는 다음 문제가 생깁니다.

- 에이전트는 회사 고유의 조직, 절차, 시스템의 약속을 모릅니다.
- 지식을 프롬프트에 많이 넣을수록 비용이 늘어납니다. 지식이 정말 도움이 되는지 재지 않으면 알 수 없습니다.
- 사람의 승인이 병목이 됩니다.
- 조직과 시스템이 바뀌면 지식이 낡습니다.
- 상시 동작하는 에이전트의 토큰 비용은 빠르게 커집니다.

## 구조 개요

| 층 | 역할 |
|---|---|
| 접수 | 채널의 메시지를 표준 업무로 바꾸고 담당 영역을 정합니다 |
| 지식 | 업무·조직·시스템·절차의 관계를 한 곳에 저장하고, 필요한 조각만 에이전트에 제공합니다 |
| 실행 | 기존 에이전트 런타임을 호출하고, 예산과 권한을 강제합니다 |
| 운영 | 사용량, 승인, 감사 기록을 관리합니다 |

## 설계 원칙

1. 외부 의존은 모두 교체 가능합니다. 런타임, 채널, 업무 시스템은 시뮬레이션 구현으로 시작하고 실제 구현으로 바꿉니다.
2. 사실은 한 곳에만 저장합니다.
3. 꼭 지켜야 하는 규칙은 글이 아니라 검사로 둡니다.
4. 지식의 효과는 정답률과 비용으로 잽니다.
5. 사람의 승인은 줄여야 할 비용으로 보고 기록합니다.

## 실행

Node.js 22.18 이상과 pnpm이 필요합니다.

```sh
pnpm install
pnpm check
pnpm crewdesk eval
pnpm crewdesk sim --out reports
```

- `eval`: 기본 배포판의 지식으로 역량 질문을 실행합니다.
- `sim`: 가상 회사에서 30일을 시뮬레이션하고 보고서를 `reports/`에 씁니다.
- `init`, `deploy`, `upgrade`: 조직별 덮어쓰기로 배포판을 배치하고 올립니다.

시뮬레이션의 비용과 한도는 가짜 값입니다. 절대값이 아니라 구성 사이의 차이를 봅니다.
